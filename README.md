# 🎯 Number Guessing Game

A simple beginner-friendly Python game where the computer randomly selects a number between 1 and 100, and the player tries to guess it.

## 📌 About the Project

The Number Guessing Game is a command-line Python project created to practice basic programming concepts such as:

* Variables
* Input and output
* Conditional statements
* While loops
* Functions
* Exception handling
* Random number generation

## 🎮 How the Game Works

1. The computer generates a random number between 1 and 100.
2. The player enters a guess.
3. The program checks the guess.
4. If the guess is too low, the program displays `Too Low`.
5. If the guess is too high, the program displays `Too High`.
6. When the player guesses correctly, the number of attempts is displayed.
7. The player can choose to play again.

## ✨ Features

* Random number generation
* Number guessing system
* Attempt counter
* Too High / Too Low hints
* Invalid input handling

```bash

```

### 2. Open the project folder

